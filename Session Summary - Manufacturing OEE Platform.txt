WORK DONE — PHASE 4: STARTUP SCRIPTS
==============================================================

Recreated / updated the following scripts at project root:

Start App.bat
  - Launches start-app.ps1 via PowerShell.

start-app.ps1
  - Locates Node.js automatically (WinGet, common paths, PATH).
  - Copies .env from .env.example if missing.
  - Installs npm dependencies if node_modules missing.
  - Kills any stale processes on ports 3001, 5174, 5176, 5178.
  - Clears Vite cache (node_modules/.vite) before each start.
  - Starts backend on port 3001 (npm run dev).
  - Waits for backend health check at /api/health.
  - Starts frontend on port 5178 with --force flag (npx vite).
  - Waits for frontend to be reachable.
  - Opens http://localhost:5178 in default browser.
  - Logs backend and frontend output to logs/ folder.

Stop App.bat
  - Kills processes on ports 3001, 5174, 5176, 5178.
